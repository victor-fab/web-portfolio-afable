# Victor Afable's Personal Portfolio

This is my personal portfolio website, built from scratch using HTML, CSS, and JavaScript. It showcases my skills, my projects, and a bit about me.

**Live Site:** [**https://victor-fab.github.io/web-portfolio-afable/**](https://victor-fab.github.io/web-portfolio-afable/)

---

## 🚀 Features
* **Modern B&W Theme:** A clean, minimalist black-and-white design.
* **Fully Responsive:** Looks great on desktops, tablets, and mobile phones.
* **Interactive Effects:** Includes a 3D-flip card, typing animation, and smooth scrolling.
* **Parallax Scrolling:** A "delayed scroll" effect on parallax sections for a modern feel.
* **Multi-Page:** A separate, connected page for my Dota 2 clips.

---

## 💻 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/victor-fab/web-portfolio-afable.git
    ```
2.  **Navigate to the folder:**
    ```bash
    cd web-portfolio-afable
    ```
3.  **Open the main file:**
    * Simply open the `index.html` file in your favorite web browser.
